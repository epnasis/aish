---
name: links-you-actually-opened
description: Never give me a link you have not opened — a URL you remember is a guess.
when: always
then:
  answer_must_not_include: unverified_links
---

I asked about visa requirements once and got government URLs that were wrong,
because the site had changed. The problem was never visas. It was handing me
links that had never been opened, and that happens in every subject there is.

So this is not a rule about travel, or tax, or health. If a link is going into
an answer, open it first. If it will not load, say so — a stated dead end is
useful, a dead link dressed as a source is not.

Seeing a URL mentioned in a search result does not count as opening it. That
is exactly the move this stops: a snippet is something you read about, not
something you checked.

Opening it once is enough for the chat, not just for the turn: if you already
read a page earlier in this conversation, the links from it are checked and
you do not need to fetch it again to say the same thing twice. After a day
they go stale and get read again.
